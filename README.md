# 🏋️ FitAI – AI Fitness Planner

**FitAI** is a web application designed to provide users with an **all-in-one fitness assistant powered by artificial intelligence**.

It allows users to manage their fitness profiles, explore exercises, identify gym equipment using AI, and discover nearby fitness centers.

The application is developed using **Java and Spring Boot**.

---

## 🚀 List of Features

### 👤 1. User Authentication and Profile

User registration and login with the ability to manage **personal information and fitness preferences**.

---

### 📸 2. AI Gym Equipment Scanner

Allows users to upload a **photo of gym equipment** and receive AI-generated information about:

- Equipment purpose
- Targeted muscle groups
- Basic usage instructions

---

### 💪 3. Exercise Explorer

Browse exercises by **muscle group**, including:

- Exercise images
- Exercise descriptions
- Targeted muscle groups

---

### 📍 4. Gym Finder Croatia

Search for **popular fitness centers in Croatian cities** and view their locations.

---

### 📱 5. Responsive User Interface

Optimized for **desktop computers, tablets, and mobile browsers**.

---

## 🛠️ Technology Stack

**Backend:** Java, Spring Boot

**Frontend:** Thymeleaf, HTML, CSS, Bootstrap

**Database:** H2 Database, Spring Data JPA

**API Communication:** REST API

**Version Control:** Git & GitHub
