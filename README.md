# 🏋️ FitAI – AI Fitness Planner

**FitAI** is a web application designed to provide users with an **all-in-one fitness assistant powered by artificial intelligence**.

The application allows users to create personal fitness profiles, generate AI-powered workout plans, explore exercises, identify gym equipment using AI, and track their workout history.

FitAI is developed using **Java and Spring Boot**.

---

## 🚀 List of Features

### 1. User Authentication and Fitness Profile
User registration and login with the ability to manage **personal information and fitness preferences**, including experience level, activity level, and weekly training frequency.

### 2. AI Workout Planner
Generates **personalized workout plans** based on the user's fitness profile and preferences.

Each workout plan contains scheduled workouts with recommended exercises, sets, and repetitions.

### 3. Exercise Explorer
Browse exercises and view relevant information, including:
- Exercise names and descriptions
- Targeted muscle groups
- Required gym equipment

### 4. AI Gym Equipment Scanner
Allows users to upload a **photo of gym equipment** and receive AI-generated information about:
- Equipment identification and purpose
- Targeted muscle groups
- Basic usage instructions
- Related exercises from the Exercise Explorer

### 5. Workout Tracking and History
Allows users to record completed workouts and review their training history, including workout dates, duration, and personal notes.

### 6. Responsive User Interface
Optimized for **desktop computers, tablets, and mobile browsers**.

- **Programming Language:** Java
